# 고충처리 자료 검색 지원 시스템 — PRD

> Product Requirements Document
> 작성일: 2026-05-22
> 버전: v0.1 (MVP 데모 단계)

## 1. 한 줄 요약

고충 조사관이 흩어진 1차 법령 자료(유권해석·의결례·재결례·판례)를 **한 화면에서 의미 기반(시맨틱) 검색**으로 찾을 수 있게 해주는 정부 업무용 웹 도구입니다.

## 2. 문제 정의 (Problem)

- 고충 조사관은 사건마다 권익위·법제처·행심위·대법원 등 **서로 다른 사이트와 다른 UI**를 오가며 자료를 찾는다.
- 각 사이트는 단어가 완전히 일치해야만 결과를 보여주는 키워드 매칭에 가깝다. "퇴직금"으로 검색해야 나오는 결정문은 "퇴직급여"로는 안 나온다.
- 신규 조사관일수록 어디서 무엇을 찾을지 가늠하는 데 시간이 길게 들고, 출처별 결과를 직접 비교·종합하는 추가 비용이 든다.

## 3. 사용자 (Users)

| 역할 | 설명 | MVP에서 다루는가 |
|------|------|----------------|
| 조사관 (investigator) | 고충 및 집단갈등조정국 조사관. 사건마다 유사 사례를 찾는다. | ✅ 1차 사용자 |
| 자료관리자 (curator) | 자료 신뢰도·태그·검수를 담당. | ❌ Phase 3 |
| 시스템관리자 (admin) | 사용자/권한/시스템 설정 담당. | ❌ Phase 3 |

## 4. 사업 목적 (Goal)

흩어진 1차 자료의 **통합 시맨틱 검색**을 통해 조사관의 자료 탐색 시간을 단축한다.

- **MVP 정량 목표**:
  - 검색 응답 시간 ≤ 2초 (Top-20 결과)
  - 최소 1종(의결례) ≥ 500건 인덱스 보유 시점에 첫 데모 가능
- **MVP 정성 목표**:
  - 조사관 3명에게 시연 → "이전 검색보다 빠르게 찾을 수 있겠다"는 피드백 받기

## 5. 핵심 가치 (Value Proposition)

1. **출처 통합**: 4개 사이트를 안 들락거려도 됨.
2. **의미 기반 검색**: "퇴직금"과 "퇴직급여"를 같은 의미로 인식.
3. **빠른 탐색**: 결과 카드 → 원문 1클릭.
4. **AI 길잡이 + 인간 결정**: 결론은 항상 조사관이. AI는 길잡이만.

## 6. 비범위 (Out of Scope)

- 결정문 자체의 **자동 작성** (AI가 결론을 내려주지 않음)
- 판례 평석·해설서 작성
- 외부망(인터넷) 사용자 대상 공개 서비스
- 모바일 네이티브 앱 (MVP는 PC 웹만, 모바일은 반응형 보조)
- 정식 운영 인증(ISMS·CSAP)·망분리 적용 — 이는 G-Cloud 이전 단계의 별도 작업

## 7. MVP 기능 (Phase 1)

### 7.1 사용자가 할 수 있는 일

- ✅ 자연어로 검색어 입력 ("층간소음 인용 사례")
- ✅ 결과 카드 리스트 보기 (상위 20개, 코사인 유사도 순)
- ✅ 자료 상세 보기 (전문, 원문 링크, 메타데이터)
- ✅ 자료 종류·연도 필터
- ✅ 환류 메모 입력 (간단형: 본인만 보임)

### 7.2 Acceptance Criteria

- [ ] 빈 검색어 입력 시 안내 메시지가 표시된다.
- [ ] 검색 결과 카드는 제목·기관·결정일·유사도 점수·요약 미리보기를 보여준다.
- [ ] 결과는 코사인 유사도 내림차순으로 정렬된다.
- [ ] 카드 클릭 시 상세 화면으로 이동하며 원문 링크가 작동한다.
- [ ] 자료 종류·연도 필터를 변경하면 결과가 즉시 갱신된다.
- [ ] 검색 응답 시간이 P95 기준 ≤ 2초이다 (인덱스 500건 가정).
- [ ] `.env`에 `GEMINI_API_KEY`, `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `KOREAN_LAW_API_KEY`(또는 `LAW_OC`)가 있어야 동작한다.
- [ ] 환경변수 누락 시 명확한 오류 메시지가 표시된다.
- [ ] API 키는 코드/Git에 절대 들어가지 않는다 (`.env`만 사용).
- [ ] Vercel에 배포된 URL을 열어 검색이 동작한다.

## 8. 기술 스택 (확정)

| 영역 | 선택 | 근거 |
|------|------|------|
| 프레임워크 | **Next.js 14+ (App Router) + TypeScript** | 한 프로젝트에서 화면+서버 동시 처리. Vercel 무료 배포. AI 코딩 호환성 최고 |
| 스타일 | **Tailwind CSS** | 빠른 UI, 인디고 톤 컨셉 적용 용이 |
| DB | **Supabase (Postgres + pgvector)** | 무료 티어, 한 서비스에서 DB·인증·파일·벡터 검색 다 됨. G-Cloud Postgres로 이전도 그대로 옮길 수 있음 |
| 임베딩 | **Gemini `gemini-embedding-001`** | 이전 레포에서 검증됨. `RETRIEVAL_DOCUMENT`/`RETRIEVAL_QUERY` 분기 |
| 자료 출처 | **법제처 Open API** | 이전 레포 동일 방식 (`KOREAN_LAW_API_KEY`) |
| 배포 | **Vercel (앱) + Supabase (DB)** | 둘 다 무료 티어 |
| 환경관리 | **`.env` + `.env.example`** | API 키는 환경변수만 사용, 절대 코드/Git에 넣지 않음 |

## 11. 위험 요소 (Risks)

| 위험 | 영향 | 완화 |
|------|------|------|
| Gemini API 한도/지연 | 검색 응답 시간 ↑ | 임베딩 결과 캐싱, 일일 한도 모니터링 |
| 법제처 API 스키마 변경 | 자료 수집 실패 | 수집 스크립트에 스키마 검증 단계 추가 |
| Supabase pgvector 인덱스 부족 | 검색 느려짐 | 데이터 1만 건 넘으면 `ivfflat`/`hnsw` 인덱스 강제 |
| 정부 자료의 라이선스 표시 누락 | 법적 리스크 | 카드/상세 화면에 출처·결정일·원문 링크 필수 노출 |
| 향후 G-Cloud 이전 시 락인 | 이전 비용 | Supabase 의존을 `lib/db.ts`로 격리 → Postgres만 있으면 어디든 이전 |
